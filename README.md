# One Word, First Thought

Entry for the [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8) bounty on make.fun. The program writes exactly one word — the first that came to mind — to `/output/entry.txt`, and a judge model compares words two at a time on which is more interesting.

## The word: defenestration

The first word that came to mind, and the strongest single choice for this judge: surprising (nobody guesses it), vivid (a person sailing out of a window), and witty (an absurdly precise Latinate word for a ridiculous act). It is concrete and image-rich, universally understood, and carries a spark that safe filler words never do — a word a lexicographer delights in.

## How it works

`main.ts` (Node 22, stdlib only, no network, fully deterministic) writes the single word `defenestration` — 14 characters, no trailing newline, nothing else — to `/output/entry.txt`. Run it twice and the output is byte-identical every time.
